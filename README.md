## 📌 About The Project

**Mini DeFi Vault** is a full-stack decentralized application (dApp) designed to simulate professional-grade institutional asset management on the blockchain. The protocol allows users to connect their Web3 wallets, execute secure asset deposits and withdrawals through immutable smart contract logic, and monitor their entire transaction history via a live on-chain event log dashboard.

This project bridges robust backend smart contract engineering with a responsive, high-performance frontend interface.

---

## 🛠️ Tech Stack

* **Smart Contract Development:** Solidity, Foundry (testing, compilation, and gas optimization)
* **Frontend Architecture:** Next.js, React, TypeScript, Tailwind CSS
* **Web3 Integration:** Ethers.js, MetaMask Wallet Provider
* **Network & Deployment:** Sepolia Testnet, Vercel

---

## ✨ Core Features

* **🔐 Secure Wallet Authentication:** Instant, seamless Web3 connection via MetaMask.
* **💰 Trustless Deposits & Withdrawals:** Direct interaction with smart contract vaults to manage liquidity securely on-chain.
* **📊 Live Transaction History:** Dynamic activity feed tracking all previous deposits, withdrawals, and user actions in real-time.
* **📱 Enterprise-Grade UI/UX:** Clean, responsive, high-contrast dashboard designed following modern DeFi protocol standards.
